# Work log

This file is a blank template on `main`. On a contribution branch, replace
this sentence with one concise, product-safe record containing:

- the user-visible behavior changed
- the domains and files affected
- the exact verification commands and results
- any remaining risk or follow-up

Never include credentials, API keys, OAuth data, account identities, provider
profile contents, private project names, machine-specific paths, proprietary
source, or unredacted logs. Maintainers clear accepted entries when preparing
the next `main` template. The work log is for pull-request review context, not
for historical operational notes.
